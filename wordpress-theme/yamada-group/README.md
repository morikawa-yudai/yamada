# YAMADA GROUP WordPress Theme

承認済みのVercelプレビューをWordPress用のオリジナルテーマへ移植したものです。

## 推奨プラグイン

- Contact Form 7（お問い合わせフォーム）

## 導入

1. yamada-group.zip を「外観 > テーマ > 新規追加」からアップロード
2. テーマを有効化
3. Contact Form 7 を有効化
4. 「山田グループ設定」で会社情報を確認
5. お問い合わせページにContact Form 7のショートコードを設定
6. 「設定 > パーマリンク」で「変更を保存」を1回実行

## 更新できる主な内容

- メイン画像・トップコピー
- 会社・拠点・電話・FAX
- 従業員数・保有車両・取引企業実績
- お知らせ
- 募集職種・給与・勤務条件
- Instagram / まるっと便リンク
